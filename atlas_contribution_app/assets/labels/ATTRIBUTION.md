# Label icons

`butterfly.svg`, `horse.svg`, and `road-horizon.svg` are unchanged assets
from @phosphor-icons/core 2.1.1 (MIT, LICENSE in this directory).
Upstream: https://github.com/phosphor-icons/core

`snake.svg` and `ring.svg` are project-authored instructional icons.
All other controls use the existing Lucide icon dependency.
These icons identify research choices, not learned visual templates.
